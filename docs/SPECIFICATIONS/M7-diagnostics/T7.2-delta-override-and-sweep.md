## Goal

1. **`--delta` for `python -m ihdm.cli.evaluate_run`.**
   - It sets the sampling noise sd (default: the run's `delta_factor × sigma`, unchanged). It
     reaches the prior noise and every reverse step exactly as `ihdm.sampling` already supports
     (`SampleRequest.delta`).
   - A non-default δ writes to its own sample and metric trees, e.g. `samples_amp-fp16_delta-0.02/`
     and `metrics_amp-fp16_delta-0.02/`. Draws under two δ values can never share a cache or a
     result file, exactly as the AMP modes are kept apart today.
   - The default path is unchanged: names, files and numbers byte-identical (regression test).
2. **128²-capable evaluation.** `evaluate_run` (and `slurm/eval/prepare_eval.py`, which writes the
   frozen seed lists and reference caches) must work on a run whose `data.image_size` is 128 and
   whose dataset is 128². Today's code assumes `W = 192` in places: the LSD bins over 0.5–96
   c/img, the octave table, the inherited-band low band, the lowpass. Generalise them so that:
   - at W = 192 every output is byte-identical to today's (regression test on the existing tiny
     fixture);
   - at W = 128 the LSD uses the bins that exist on that grid, and the octaves stop at W/2. The
     rule is documented in the module docstring and in the log, with a proposed amendment to
     `05-metrics.md`.
   - Test with a synthetic 128² dataset and run fixture. No real 128² dataset exists until T7.1
     merges.
3. **The δ sweep** (Picasso, A100, fp16 as D20):
   - Runs: `ixi_A0_s1`, `ixi_A3_s1`, `lsun_church_A0_s1`, `lsun_church_A3_s1` in
     `/mnt/home/users/tic_163_uma/mpascual/fscratch/runs/ihdm/`, checkpoint 60,000 (EMA).
   - δ/σ ∈ {1.25, 2, 3} (σ = 0.01, so δ ∈ {0.0125, 0.02, 0.03}).
   - Per (run, δ), the 500-seed LSD set: the frozen `eval_seeds_500.npy`, the curve's rng seed
     2026. The noise stream is shared across δ, which makes the comparisons paired. It yields the
     LSD, the octaves and the variance ratio.
   - Per (run, δ), a 500-sample final set (a prefix of the frozen 2,000 list) yields KID, FID,
     precision, recall, density, coverage and $M$.
   - Per (run, δ), held-out diversity of 40 seeds × 5 samples yields $D_{pix}$, $D_{lp}$ and the
     inherited band.
   - Budget ≤ 10 A100-h in total. Prefer fewer chains if the code allows it without restructuring
     `run_eval`.
   - **Reproduction anchor:** at δ = 1.25σ the 500-seed LSD must equal the collection's
     `lsd_060000` of that run within 0.003. Values: `ixi_A0_s1` 0.2497, `ixi_A3_s1` 0.08400,
     `lsun_church_A0_s1` 1.445, `lsun_church_A3_s1` 0.6416 (`docs/RESULTS/tables/t7_t_tau.md`).
   - Never write into the run directories on FSCRATCH. Sample on `$LOCALSCRATCH` and copy back one
     archive or JSON per task to `~/execs/ihdm/diag_eval/delta_sweep/`, as the eval array does.
   - **Prepare the job (the `picasso-sbatch` skill conventions; `slurm/diag_eval/`), smoke it if
     cheap, then stop and report; `main` replies GO after review.** After GO: run, collect, write
     `docs/RESULTS/delta_sweep/` (a JSON with every number and a `README.md` table per run × δ),
     and record the pre-registered reading of `M7-diagnostics/README.md`.
