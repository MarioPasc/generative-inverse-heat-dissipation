## Protocol (fixed before any diagnostic number exists)

- **Sampling.** At each of the 4 checkpoints, per run: 500 training-seeded samples, i.e. the
  dataset's frozen `eval_seeds_500.npy`, rng 2026, sample batch 32, fp16 (D20), default δ.
- **Metrics per checkpoint**, all against the run's own 800-image `ref` split:
  - KID with its CI, FID, precision, recall, density and coverage (Inception, k = 5);
  - LSD, the octave profile and the variance ratio, on the W rule of `05-metrics.md` (M7
    amendment);
  - M and seed-NN fraction (optional, useful).
- **Late window.** The late-window value of each quantity is the mean over the 4 checkpoints.
- **Reading.** A factor lifts the failure if its late-window precision is ≥ 0.10, **and** ≥ 10×
  the baseline's, **and** its KID is ≤ 0.5× the baseline's. Report the 2 × 2 reading table of the
  README.
- **Grids.** Also produce a sample grid per run: 16 samples at 60k next to their seeds. These are
  the descriptive evidence.

## Code needed

`evaluate_run` computes the Inception metrics and M only at the run's final step, the
`final_step = max(table)` branch of `ihdm/metrics/run_eval.py`. Add an option, e.g.
`--inception-steps 45000,50000,55000,60000`. With it, the Inception metrics (and M) are computed
on each listed step's LSD set and stored in that step's `ckpt_<step>.json` under an `inception`
block (and `M` / `seed_nn_fraction`).
