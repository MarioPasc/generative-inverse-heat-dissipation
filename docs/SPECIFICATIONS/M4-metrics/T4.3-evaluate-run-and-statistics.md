# T4.3 — `evaluate_run` CLI, Inception metrics, statistics

Milestone M4 · mode: single · model: opus5-high · depends on: T4.1, T4.2 · closes M4

## Mission

One command that evaluates one run: for each EMA checkpoint, draw the LSD samples (training
seeds) and compute LSD; at the final checkpoint, additionally draw the 5k training-seeded samples
(seed index recorded per sample) for FID/KID/recall/coverage **and $M$**, and the 40 × 50
held-out-seeded samples for diversity, the inherited band and the PCA scores; write the result
files of `05-metrics.md` §9 (KID is the headline Inception metric; every FID carries its
$N_{\text{ref}}$). Plus the statistics module used by the
analysis (bootstrap over seeds, permutation test, paired deltas, interaction).

## Ownership

`ihdm/cli/evaluate_run.py`, `ihdm/metrics/inception.py` (clean-fid + prdc wrappers),
`ihdm/stats/**`, `tests/stats/**`, `tests/metrics/test_inception.py`, `tests/cli/test_evaluate_run.py`.

## Specification

1. `python -m ihdm.cli.evaluate_run --run <workdir> [--ckpts all|final|<list>] [--n-lsd 2000]
   [--n-lsd-intermediate 1000] [--n-seeds 40 --n-per-seed 50] [--fid 5000] [--skip-inception]
   [--device cuda]` — idempotent per checkpoint (skips `metrics/ckpt_<step>.json` that exist unless
   `--force`); samples cached under `<workdir>/samples/<ckpt>/` in the `sample_ckpt` layout so they
   can be reused by the figures; `metrics/summary.json` merged at the end.
2. `ihdm/metrics/inception.py`: `inception_features(images_u8[N,H,W], device, batch=64) ->
   np.ndarray[N,2048]` using clean-fid's extractor (`cleanfid.features.build_feature_extractor
   ("clean", device)` + `get_batch_features` on in-memory tensors, grayscale replicated to RGB,
   clean-fid's own resize), **never writing PNG folders** (Picasso's file quota has ≈ 30k files of
   headroom; 5k PNGs per run would exhaust it); `fid_from_features(f_a, f_b)` and
   `kid_from_features(f_a, f_b)` reusing `cleanfid.fid.frechet_distance` / `kernel_distance`;
   `recall_coverage(f_samples, f_ref, k=5)` with `prdc` on the same features. Inception weights
   are downloaded on first use; the Picasso worker of T5.1 must pre-download them on the login
   node (document the cache path). Reference features are cached per dataset under
   `$IHDM_DATA_ROOT/<id>/_features_inception_ref.npy`.
3. `ihdm/stats/bootstrap.py`: `paired_delta(a: dict[seed, float], b: dict[seed, float])`,
   `bootstrap_ci(values, n_boot=10000, alpha=0.05, rng_seed=0)`, `interaction(delta_mri: array,
   delta_photo: array)` with its CI, `permutation_test(cell_a, cell_b, n_perm=10000, exact_below=7)`
   per `05` §8; `ihdm/stats/tables.py`: `cell_table(results: dict[run_id, summary]) ->
   pandas.DataFrame` (dataset, arm, seed, metric columns).
4. Tests: bootstrap CI on a hand-made sample matches a known percentile interval; the exact
   permutation enumerates $\binom{6}{3} = 20$ assignments; `interaction` sign; `evaluate_run` on a
   tiny synthetic run (smoke checkpoint from the T2.2 fixture, 8 × 32² dataset, `--skip-inception`,
   `--n-lsd 8 --n-seeds 2 --n-per-seed 3`) produces the JSON files with the expected keys;
   `test_inception` is `integration` (needs the weights) and runs FID of a set against itself
   (≈ 0) on 64 images.

## Acceptance

1. `pytest tests/stats tests/cli -q` green; `ruff` clean.
2. `evaluate_run` completes on the local pilot run (`--skip-inception` allowed if the download is blocked; say so) and the JSON files match `05` §9.
3. Log at `docs/AGENT-LOGS/M4-metrics/T4.3-evaluate-run-and-statistics.md`.
