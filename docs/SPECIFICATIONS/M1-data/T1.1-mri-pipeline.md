# T1.1 — MRI pipeline: rigid MNI152 registration, slicing, windowing, splits, QC

Milestone M1 · mode: parallel with T1.2 · model: opus5-xhigh · depends on: T0.1 · unblocks: T1.3

## Mission

Turn the raw IXI T1 (581 NIfTI volumes) and OASIS-1 first-session MPRAGE (416 Analyze volumes)
into `$IHDM_DATA_ROOT/ixi/` and `$IHDM_DATA_ROOT/oasis1/` in the standard format
(`03-data-format.md`): 400 subjects × 10 axial slices each, rigidly registered to
MNI152NLin2009cAsym 1 mm, 192-px window centred on the MNI in-plane origin, intensity scaled by
the foreground 99th percentile with the background noise kept, `uint8`, subject-level splits,
validated, with the registration quality gate and orientation sheets in `qc/`.

## Specification

1. **Raw loading** (`raw_mri.py`): `list_subjects(cohort) -> list[RawVolumeRef]` (sorted by subject
   id, one volume per subject) and `load_sitk(ref) -> sitk.Image` returning a correctly oriented
   image in physical space (direction cosines set so that the image is RAS-consistent). For
   Analyze, apply the ported axis map and set spacing/direction explicitly. `PreprocessError` on
   unreadable files.
2. **Registration** (`registration.py`): `RegistrationConfig(frozen dataclass)` with the values:
   Euler3D transform (6 dof), `CenteredTransformInitializer` (moments), Mattes mutual information
   (50 bins), metric sampling random 20%, fixed-image mask = the template brain mask dilated by
   10 mm (metric region only), shrink factors (4, 2, 1), smoothing sigmas (2, 1, 0) mm, gradient
   descent with `SetOptimizerAsRegularStepGradientDescent` or LBFGS (one choice, justified in the
   log), max 300 iterations per level, `SetOptimizerScalesFromPhysicalShift`. `register(moving,
   template, mask, cfg) -> RegistrationResult(transform, final_metric, iterations, stop_condition)`.
   **One resampling**: `resample_to_template(moving, template, transform) -> sitk.Image` with
   `sitk.ResampleImageFilter` on the template grid, B-spline interpolation of order 3, default
   value 0, negative overshoot clipped to 0. Each registered volume is cached as
   `_cache/registered/<cohort>/<subject>.nii.gz` (float32) with a sidecar JSON
   (metric, iterations, transform parameters); the CLI skips cached subjects unless `--force`.
   Set `sitk.ProcessObject_SetGlobalDefaultNumberOfThreads(1)` in workers and use
   `multiprocessing.Pool(processes=--workers, default 20)`.
3. **Intensity** (`mri.py: scale_intensity`): per registered volume, foreground = template brain
   mask dilated 10 mm; `p99 = percentile(volume[foreground], 99)`; `x = clip(volume / p99, 0, 1)`;
   no low clip. Quantise `np.round(x * 255).astype(np.uint8)` at slice time.
4. **Slices and window** (`mri.py: extract_slices`): voxel $z$ indices
   `[55, 63, 71, 79, 87, 96, 104, 112, 120, 128]` of the template grid; the in-plane window is the
   192 × 192 block centred on the voxel of the MNI origin ($x = 0, y = 0$ mm), computed from the
   template affine (do not hard-code 96/132; derive and assert). Array orientation per
   `03-data-format.md` §5: first axis anterior → posterior (top row = anterior), second axis
   subject-left → subject-right. Record `z_mm` from the affine.
5. **Quality gate** (`qc.py`): (a) `registration_sheet.png`: 10 random registered subjects per
   cohort at slice index 5 with the template brain-mask outline overlaid (green) and the template
   itself as the first tile; (b) `metric_distribution.png` + `registration_report.md` with the
   final metric per subject, iterations, stop condition, and outliers (metric worse than
   median + 3 × MAD) marked `FAIL`. *Amended 2026-09-22 (orchestrator, after T1.1's measurements):*
   stopping at the 300-iteration cap on the finest level is **not** a failure (about half of IXI
   reaches the cap with a converged metric; the optimiser grinds in a flat valley); the cap rate
   is recorded per subject and in `meta.json.parameters.quality_gate`, and the FAIL rule is the
   metric rule plus any subject flagged by eye on the registration sheet; (c) `orientation_sheet.png`: for 4
   subjects per cohort, the raw volume's three mid-planes before registration and the registered
   slice 5 after, with `A`/`P`/`L`/`R` labels, plus the *template* processed by the same slicing
   code; (d) `levels_sheet.png`: one subject, its 10 slices; (e) `intensity_sheet.png`: histogram
   of the final uint8 values per cohort and the fraction of exactly-zero pixels.
6. **Subject selection and splits**: register all subjects; exclude `FAIL`s; take the first 400 of
   `np.random.default_rng(2026).permutation(sorted(passing_ids))`; `split_by_subject` from
   `ihdm.data.format` (rng 2026, 320/80/40). If fewer than 400 pass in a cohort, use all that pass,
   message `main` immediately, and record it.
7. **CLI**: `python -m ihdm.cli.preprocess_mri --cohort ixi|oasis1 [--workers 20] [--limit N]
   [--force] [--out $IHDM_DATA_ROOT]`; writes the dataset with `write_dataset`, runs
   `validate_dataset`, exits non-zero on violations, prints a one-line summary (subjects
   registered / passed / used, wall time, padding fraction). `meta.json.parameters` holds every
   value above; `meta.json.counts` as in `03-data-format.md` §4.
8. **Tests** (synthetic, fast): a synthetic "head" phantom (ellipsoid with a brighter inner
   ellipsoid) rotated by 8° and translated 6 mm is registered back to itself within 0.5 mm / 0.5°
   (`test_registration.py`); `extract_slices` on the template returns arrays of shape
   `(10, 192, 192)` with the expected orientation (assert the anterior half of the template's
   brain mask at slice 5 has more mask pixels in the top half than the bottom half? No: assert
   using the affine, i.e. the row with the largest $y$ is row 0); `scale_intensity` on a phantom;
   the splits are subject-disjoint. Mark the real-template tests `integration` (skip if absent).

## Resource limits

Up to 20 processes, ≤ 24 GB RAM total (check `free -g`); the GPU is not used; the data disk has
3.6 TB free. Expected wall time ≈ 1 h per cohort. Run IXI first, then OASIS-1.

## Acceptance

1. `$IHDM_DATA_ROOT/ixi` and `oasis1` validate (`validate_dataset == []`), 4000 images each.
2. `qc/registration_sheet.png` shows the template outline on the subjects' skull/brain at slice 5 for both cohorts; `registration_report.md` lists failures (< 5% expected).
3. `qc/orientation_sheet.png` shows anterior at the top and subject-left on the image left for both cohorts and for the template.
4. `meta.json` complete; `counts.padding_fraction` recorded; `parameters.orientation` documented.
5. `pytest tests/preprocess -q` green; `ruff` clean.
6. Log at `docs/AGENT-LOGS/M1-data/T1.1-mri-pipeline.md` with the QC numbers (pass counts, metric median/MAD, wall time) and the decisions taken (optimiser, axis map).
