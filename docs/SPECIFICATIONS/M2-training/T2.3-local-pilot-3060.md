# T2.3 — Local pilot on the RTX 3060: throughput, memory, stability, artefacts

Milestone M2 · mode: single, holds the GPU · model: opus5-high · depends on: T2.1, T2.2 merged · unblocks: M3

## Mission

Run the training harness for real on this workstation's RTX 3060 (12 GB) and report what the
Picasso array needs to know: iterations per second and peak memory at $192^2$ for batch sizes
8/16/32 (with AMP), loss stability at lr $2\times10^{-4}$, that every artefact of `04` §3 appears
at the right cadence, that resume works after a kill, and that the offline sampler loads a pilot
checkpoint. No recipe change is made here except the one allowed fallback (lr to $10^{-4}$ if the
loss diverges), which is a decision for `main`.

## Ownership

`docs/RESULTS/pilot_3060.md`, `configs/spectral/arms.py` (only the `optim.lr` line, only if `main`
approves the fallback), `runs/pilot_*` (git-ignored). Nothing else.

## Procedure

1. `pytest -q` in the env; `nvidia-smi` idle check (nothing else may use the GPU while you run).
2. Memory sweep: `ixi,A0` with `--config.training.batch_size={8,16,32}` and `n_iters=60`,
   `log_every=10`; record `gpu_mem_peak_gb`, `it_per_s`, `img_per_s`. If 32 does not fit, say so.
3. Pilot runs, batch 16, `n_iters=1000`, `ckpt_every=250`, `grid_every=250`, `eval_every=250`:
   `ixi,A0` seed 1 and `ixi,A3` seed 1, then `lsun_church,A0` seed 1 for 300 iterations. Record
   the loss curve (train and eval), the per-octave losses at the last log line, the grids at
   250/500/1000 (do they show head-shaped / building-shaped structure by 1000?), wall time.
4. Resume test: kill `ixi,A0` at ≈ step 600 (SIGTERM), restart with the same command, confirm the
   `resume` line and that `ema_iter_000750.pt` and `001000.pt` are produced.
5. Sampler: `python -m ihdm.cli.sample_ckpt --run runs/pilot_ixi_A0_s1 --ckpt ema_iter_001000.pt
   --source seed --n-seeds 4 --n-per-seed 50 --out runs/pilot_samples` → shapes, wall time per
   sample, preview attached to the log.
6. Estimate the A100 time per 20k-iteration run at batch 32 and 64 (assume 3–4× the 3060
   throughput; state the assumption) and the memory at batch 64 by linear extrapolation.

## Acceptance

1. `docs/RESULTS/pilot_3060.md` with the tables (batch × {peak GB, it/s, img/s}), the loss curves
   (PNG in `docs/RESULTS/pilot_3060/`), the grids, the resume evidence, the sampler evidence and
   the A100 estimates.
2. A statement, with numbers, on stability at lr $2\times10^{-4}$ (no NaN, loss decreasing over
   1k iterations) or the fallback request to `main`.
3. Log at `docs/AGENT-LOGS/M2-training/T2.3-local-pilot-3060.md`.
