# T6.2 — Figures for the report

Milestone M6 · mode: ‖ with T6.1 (disjoint files) · model: opus55-high · depends on: T5.2 ·
input: a `results/` folder written by `python -m ihdm.cli.collect_results`, nothing else

## Mission

`python -m ihdm.cli.figures --results <results_dir> --out docs/RESULTS/figures/` draws the report's
figures as vector PDF with a PNG preview, in matplotlib. They use the report template widths:
3.3 in single column, 6.75 in full width. `docs/RESULTS/figures/README.md` gives one caption draft
per figure, stating exactly what is plotted and the n behind it. The command is written and tested
now on the 24-run partial collection and on synthetic results, and rerun by `main` on the final
collection.

## Figures (`M6-analysis/README.md` sketch, updated for 60k)

1. **LSD versus iteration** per dataset: 12 checkpoints, 5k…60k. Arms are lines (seed mean), seeds
   are thin lines. Show the A0 final LSD as the $T_\tau$ reference, and mark the 40k → 60k
   extension (D22).
2. **The per-octave LSD profile** at the final checkpoint, per dataset and arm.
3. **Diversity ($D_{pix}$, $D_{lp}$) and memorisation ($M$, $M_{lp}$)** per dataset and arm, one
   point per seed.
4. **PCA around the seed**: two seeds, A0 vs A3, IXI vs Churches. Use the PCA sidecars copied by
   T5.2 into `results/runs/<run_id>/`.
5. **The inherited band**: the measured versus predicted radial curve, for both terminal blurs.
   Take the arrays from `final.json`.
6. **Sample grids**: the training grids at 60k (`grid_final.png`), A0 and A3 for each dataset.
   Include `lsun_church_A3_s1` and state its right-edge stripe artefact in the caption.
7. **The training sanity panel**: loss, it/s and the per-octave loss from
   `metrics.canonical.jsonl`, which is already cleaned of run 11's abandoned segment. Mark the
   extension start at 40,001.

## Rules

- **Dataviz.** Follow the `dataviz` skill: consistent colours per arm, the same palette in every
  figure, colour-blind safe, no chart junk, readable at print size. Set fonts and sizes once in a
  style helper.
- **Missing data.** A figure that needs a missing run draws what exists and says "n/N runs" in
  its caption draft; nothing is silently dropped.
- **Deterministic output.** Fix `svg.hashsalt`, strip metadata dates from the PDFs, and use no
  randomness, so that a rerun on the same results is byte-stable where matplotlib allows.
