# T3.3 — Full training array on Picasso (30 runs)

Milestone M3 · mode: single · model: opus5-high, invokes the `picasso-sbatch` skill · depends on: T3.2 · closes M3

## Mission

Write the launcher/worker pair with the `picasso-sbatch` skill and submit the 30 training runs of
`00-overview.md` §1 as a SLURM job array in tier order, with the resume rule of D10 built into the
worker, and record the submission.

## Ownership

`slurm/array/**`, `slurm/array/cells.csv` (the run table), `docs/RESULTS/submissions.md`.

## Specification

1. `cells.csv` columns `index,run_id,dataset_id,arm,seed,tier` — tier 1: `{ixi, lsun_church} × A0 ×
   {1,2,3}` and `× A3 × {1,2,3}` (12); tier 2: `{ixi, lsun_church} × {A1, A2} × {1,2}` (8) and
   `lsun_church × A2p × {1,2}` (2); tier 3: `{oasis1, lsun_bedroom} × {A0, A3} × {1,2}` (8).
   Index 0–29 follows this order so that lower indices start first.
2. Worker: `cd` to the repo; `module load` and conda activation as in the skill; `IHDM_DATA_ROOT`,
   `IHDM_RUN_ROOT=$FSCRATCH/runs/ihdm`; read its row from `cells.csv` by `$SLURM_ARRAY_TASK_ID`;
   `python train.py --config configs/spectral/arms.py:<dataset>,<arm> --config.seed=<seed>
   --config.training.n_iters=${N_ITERS:-20000} --workdir $IHDM_RUN_ROOT/<run_id>`; exit code
   propagated; `DONE` checked at the end. Because the trainer resumes from
   `checkpoints-meta/checkpoint.pth`, re-submitting a task index after a timeout continues the run,
   and submitting with `N_ITERS=30000` extends it (D10) — document both in `slurm/array/README.md`.
3. Launcher: `--array=0-29%<concurrency>` with the concurrency chosen from the QOS GPU cap
   (`medium`: gpu=23 per user; use `%8` unless `main` says otherwise), `--constraint=a100
   --gres=gpu:1 --cpus-per-task=8 --mem=48G --time=<from T3.2>`, `--output/--error` to
   `~/execs/ihdm/logs/train_%A_%a.out`; `sbatch --test-only` then submit; capture the job id per
   the skill's rule; print the monitoring commands.
4. `docs/RESULTS/submissions.md`: date, job id, array spec, `--time`, batch size, `n_iters`, the
   cells table, the D10 rule, and how to resubmit failed indices
   (`sbatch --array=<idx> ...`).

## Acceptance

1. `sbatch --test-only` passed; the array is submitted; `squeue -u mpascual` shows it.
2. `submissions.md` complete; `slurm/array/README.md` explains resume and extension.
3. Log at `docs/AGENT-LOGS/M3-picasso/T3.3-full-array-submission.md`.
