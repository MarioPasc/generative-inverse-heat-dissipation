## Specification

1. `git clone https://github.com/MarioPasc/generative-inverse-heat-dissipation` into the repos
   path (branch `main`; record the SHA). Never edit files on Picasso by hand: every change is a
   commit pushed from here and pulled there.
2. `slurm/setup/create_env.sbatch`: CPU job that runs `conda env create -f environment.yml -p
   <conda_envs>/ihdm` then `pip install -e .`; log to `~/execs/ihdm/logs/`. Torch wheels from
   PyPI (CUDA 12.x bundled); verify the driver on a GPU node supports it in step 4.
3. `slurm/setup/sync_data.sh`: `rsync -avh --progress` of the four dataset folders (with `qc/`) to
   the datasets path; then `ssh picasso sha256sum` of each `images.npy` against `meta.json`.
4. `slurm/setup/import_check.sbatch`: GPU job (`short`, 30 min, 8 cores, 32 GB): `nvidia-smi`,
   `python -c "import torch; print(torch.__version__, torch.version.cuda,
   torch.cuda.get_device_name())"`, `pytest -q` (all non-integration tests),
   `python -m ihdm.cli.validate_dataset` on `ixi` and `lsun_church` with
   `IHDM_DATA_ROOT` set to the datasets path (add this tiny CLI if T0.1 did not; it only calls
   `validate_dataset`), and a 20-iteration `ixi,A0` run with `--config.training.n_iters=20
   --config.training.ckpt_every=10` into `<runs>/import_check/`.
5. `docs/RESULTS/picasso_setup.md`: SHA cloned, env path and creation log excerpt, torch/CUDA
   versions and driver, `pytest` summary, dataset hashes, the 20-iteration run's `metrics.jsonl`
   tail, quota before/after, job ids.
