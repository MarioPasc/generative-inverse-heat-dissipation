**Decisions taken during the work** (each with the alternative rejected and why):
- **Arm colours via `style.arm_style(arm).color`.** The prompt names `style.ARMS`, but no such
  symbol exists at `cc819fc` (`style.py` exports `arm_style`; plan §5 said main would add the
  paper constants there before W16, which did not happen). The colours are the same hex values
  as plan §0. Rejected: editing `style.py` (forbidden) and hard-coding the hex values (two sources
  of truth).
- **Verification 1 uses the released `DCTBlur` built under a float64 default dtype.** `DCTBlur`
  creates its frequencies with `torch.linspace` and its sigmas with `torch.tensor`, so in the
  default float32 the exponent λt carries ~1e-7 relative rounding, i.e. > 1e-6 in d² once λt > 5:
  the 1e-6 test would fail for a reason unrelated to the mapping. Rejected: float32 `DCTBlur`.
  The tolerance is 1e-6 relative plus a 1e-12 absolute floor for octaves whose prediction
  underflows (exp(−hundreds) at σ = 96), where a relative error is undefined.
- **The figure uses `heat_blur`, the `DCTBlur` formula in NumPy/SciPy**, tested equal to the
  released operator to 1e-12 for σ ∈ {2, 8, 24, 96}. Rejected: torch in the drawing path.
- **(Superseded in review round 1, see §9.) Rug counts per σ_B octave, centred on each octave's
  c-range (c = 43.2/σ), with faint octave separators.** This keeps the printed counts equal to `data_profile.md` §5 and the ticket.
  Rejected: re-binning the levels on the c/img octaves of the bars. That would align the counts
  with the bars, but the numbers would no longer be the verified ones.
- **Three octave shares annotated (IXI 4.1% and 29.8%, Churches 23.8%), not all eight.** These are
  the framing's numbers. Rejected: eight bar labels; at 7 pt they collide with the 1/f² line
  (12.5%) and the Churches outline.
- **Churches outline dashed, 1/f² line dotted.** The plan calls both "dashed", which makes two
  reference lines indistinguishable. Rejected: identical dash patterns.
- **A three-entry legend at the top right, running 0.045 axis widths into the gutter.** It sits

  taller y range (it compresses the bars).
- **The inherited shares are printed once, in panel (a)'s corner.** Panel (b)'s row labels are
  "default prior u(96 px)" and "matched prior u(24 px)". Rejected: repeating 0.3%/8.5% in (b); in
  iteration 1 those labels overflowed the right edge.
- **Thumbnails: raw 192² arrays in the PDF and SVG, antialiased in the PNG.** The PDF and SVG use
