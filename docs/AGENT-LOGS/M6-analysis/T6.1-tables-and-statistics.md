**Decisions taken during the work** (each with the alternative rejected and why). Choices 2–9
were messaged to `main` at 09:50 and accepted; `main` changed choice 1.

1. **T_tau threshold.** Primary is the same-seed A0 run's `lsd_060000`, the curve's own 500-seed
   CRN estimator. The sensitivity threshold is its `lsd_final` (2k set), printed as a labelled
   column (table 7) and as a sensitivity endpoint row (tables 2–6). My proposal was `lsd_final`
   as primary, because `evaluation_plan.md` §8 and `collection.md` name it. `main` rejected it:
   T_tau is a statement about curves, and the 0.003 set mismatch on IXI A0 s1 is as large as the
   gate's resolution (±0.0026).
2. **LSD CI resamples seeds only.** §8's "for LSD also resample samples" needs the sample
   stacks, and they are not in `results/`, the ticket's only input. I considered approximating
   the sample level from nothing and rejected it: it would be an invented statistic.
3. **Paired contrast.** CI from `ihdm.stats.paired_delta` over the seeds both cells have. p from
   `ihdm.stats.permutation_test` on the same seed-matched subset, so A1/A2/A2′ use A0 seeds {1,2}:
   2 vs 2, 6 assignments, p_min 1/3. Using all three A0 seeds was rejected: the permutation
   statistic would then differ from the paired point estimate.
4. **Interaction p.** An exact permutation of the dataset label over the 6 pooled per-seed A3−A0
   differences (20 assignments, p_min 0.1). This is §8's "permute over the pooled seeds of the
   two cells" applied to the two sets of differences. The CI is `ihdm.stats.interaction`. Only
   IXI vs Churches enters; pooling the transfer datasets was rejected because the ticket names
   IXI vs Churches and gives the transfer cells no p-values.
5. **3-seed CI = [min, max].** With 3 seeds the percentile CI is exactly the range of the three
   differences (P(all draws = min) = 1/27 > 2.5%), so "CI excludes 0" means "the 3 seeds agree
   in sign", with coverage 75% under a symmetric null (50% with 2 seeds). The README puts this at
   the top, as `main` asked. A test pins it
   (`test_with_three_seeds_the_interval_is_the_range_of_the_paired_differences`).
6. **Decomposition.** Share = mean_{s∈{1,2}}(A1−A0) / mean_{s∈{1,2}}(A3−A0), and the same for
   A2. There is no CI. A share is flagged "not interpretable" when the 3-seed A3−A0 CI contains 0.
   Using A3's 3-seed mean as the denominator was rejected: it mixes seed sets.
7. **A2′ control** adds A2′−A2, the same §8 paired procedure between two non-A0 arms, beside
   A2′−A0 and A2−A0.
8. **Transfer.** Development Δ over 3 seeds, transfer Δ over 2, sign agreement of the means,
   per-seed transfer Δ and Δ/mean(A0). No CI, no p.
9. **T_tau "not reached"** makes a contrast "not computable". Imputing the budget or +∞ was
   rejected as invented.
10. **No statistic on a subset of seeds.** A contrast needing a missing run is marked
    `incomplete: n/N runs` and carries no numbers. Computing on the available seeds was rejected:
    it would change the estimand silently.
11. **Sources.** `index.csv` is the primary source: it is T5.2's contract and the only place a
    missing run still has a row. Each evaluated run's `summary.json` is read through
    `ihdm.stats.cell_table`, which (a) cross-checks every number of `index.csv` (a mismatch
    refuses the folder) and (b) supplies the low-band inherited shares that only summaries hold.
    I considered building the table from `cell_table` alone and rejected it, because missing runs
    have no summary.
12. **Refusals and exit codes** mirror `collect_results`: 0 complete, 1 unusable (verdict `FAIL`,
    index/summary disagreement), 2 not a results folder, 3 written but incomplete. The CLI
    overwrites only its own files and never the README.
13. **Table 1 split into 1a (fidelity) and 1b (mechanism)**, so each fits a page. Table 8 (gates)
    was added for the honesty requirement "report both gates' numbers".
14. **Exploratory settling step** (`main`, after my report that T_tau is degenerate): the first
    checkpoint after which the curve stays ≤ the primary threshold to 60k. It is labelled
    "exploratory, defined after seeing the data (2026-09-29), not pre-registered" everywhere and
    reported descriptively only (table 9 and a column of table 7).
15. **Δ/A0 columns in table 3** (`main` accepted, descriptive). After seeing the output I
    restricted them, and the same column of table 6, to positive ratio-scale endpoints. On recall
    with Churches A0 ≈ 0.003, the ratio read +3,129%. On the inherited share, A0 IXI is −0.85,
    and the ratio flipped the sign (−108% for a +0.92 gain).
16. **Test module renamed** from the ticket's `tests/analysis/test_tables.py` to
    `tests/analysis/test_analysis_tables.py`. The ticket's name collides with
    `tests/stats/test_tables.py`: tests/ has no `__init__.py`, and pytest's rootdir import mode
    needs unique basenames, so the full suite failed at collection. Adding `__init__.py` files
    was rejected because it changes the import mode repo-wide, outside my files. `main` was
    messaged.
17. **Short not-computable reasons** ("T_τ not reached (A2 s1)") keep the reason inside a cell.
    The full run ids stay in `tables.json` `required`/`missing`. This cut the LaTeX overfull of 2b
    from 115 pt to 62 pt.
