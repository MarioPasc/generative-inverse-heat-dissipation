## 2. Plan and decisions

**Restatement:** build a PyTorch-tutorial-style notebook (jupytext `.py` as source, executed `.ipynb`, HTML export) that explains the two IHDM changes with numbers computed from tracked files, plus a CLI that rebuilds the small `assets/` it reads, tests, and a README top section.

**Decisions:**
- Images are exported with a manifest (`assets/images/manifest.json`) holding row/subject/split, so the notebook labels come from data — hard-coding labels in the notebook rejected (no provenance).
- Outputs carry no timestamp or git SHA, only SHA-256 of their sources — a commit hash in the JSON rejected because it breaks the byte-identical rebuild of AC4.
- `--images dataset:row` option on the CLI so the fast test can run `main()` on the synthetic fixture — a test of the internals only rejected (would not cover the CLI).
- Distance seed means are taken from the "seed mean" rows of `F2.md` (`distance_seed_mean`) — averaging the rounded per-run medians rejected: it gives matched F seed 0.892 and H seed 0.868 where F2.md (unrounded) prints 0.893 and 0.867.
- Section 7 plotting lives in the optional `ihdm/analysis/tutorial.py` (three `plot_*` helpers); all computations of Sections 3–6 stay in notebook cells calling `ihdm` functions.
- The `c^-2` dotted reference line of Figure 4a was dropped: the synthetic spectrum is already the slope −2 line.
- Section 5 prior figure uses the two *training* images (IXI 3311, Churches 1180), since prior seeds of set F are training images; the Section 3 blur figure uses IXI 3705 (the report's Figure 1 slice).
- The setup cell prints `ihdm`'s path relative to the repository (and fails if it is outside), so no absolute local path ends up in the committed outputs.
- Dependency pins: lower bounds equal to the installed versions (`jupytext>=1.19.6`, `nbclient>=0.11.0`, `nbconvert>=7.17.2`, `nbformat>=5.11.1`, `ipykernel>=7.4.0`), matching the repo's `>=` style.

**Assumptions:** none that change results. `ihdm.__file__` and `model_code.__file__` resolved inside wt/T9.1 when run from the worktree root (checked; no PYTHONPATH needed). Ruff 0.16.8 was already installed in env `ihdm`.
